# Guide: how to show Agent 8 what you see in your head

Why results drift: Agent 8 cannot see your picture. Words like "chunky", "busy", "Elite style" mean something different to each of us. The fix is not better words, it is showing things and correcting early.

## 1. Bring pictures, not descriptions (10 minutes, biggest effect)
Make a "reference sheet" of 6 to 10 images and give it to Agent 8 before it builds anything:
- 3 to 4 photos or screenshots of cockpits you LIKE (Elite Dangerous Asp/Cobra cockpit, PS1-era space games, real aircraft cockpits).
- 1 to 2 you DON'T like, with one line why ("too clean", "too empty").
- 1 picture for the mood/light (dark room, glowing screens).
- Optional: a rough sketch on paper or in any drawing app, even stick-figure level: window on top, dashboard at the bottom, dog on the right. Photograph it.
Mark each picture with ONE sentence: "I want THIS part of it" (the frame, the dashboard, the light). Never "make it like this" for the whole thing.

## 2. Use the "three words + one number" rule for each ship
For each cockpit write: three adjectives, one thing it must NOT be, and one proportion. Example: "cramped, warm, cluttered. NOT a modern airliner. Window takes the top half." The proportion (how much window, how big the dashboard) matters more than any adjective.

## 3. Change the process: options before building
Ask Agent 8 to start every new design with a "thumbnail round" before modelling:
1. Agent 8 draws 3 very rough options per cockpit (flat pictures or simple blocks, 5 minutes each), labelled A, B, C.
2. You choose, and say "A, but the frame thicker, dashboard higher".
3. Only then does it build the model.
Cost: one extra step. Saving: no more finished models that are far off.

## 4. Review by pointing, not by feeling
When you look at a model in the viewer, answer in this shape, per cockpit:
- KEEP: (what is right)
- CHANGE: (one to three things, each as "more/less/bigger/smaller/higher/lower" or "like picture 3")
- WRONG IN KIND: (something that is simply not what you meant)
Take a screenshot, draw on it (arrows, circles), and send it. A circled screenshot beats a paragraph.

## 5. Ask Agent 8 to compare against the reference
After each batch, Agent 8 must show your reference pictures next to the model in the same view and list in plain words: "matches / does not match" for each marked part. If it cannot match something (budget of 2000 triangles, phone speed), it must say so before you spend time looking.

## 6. Know the limits of the style
Everything is made of simple low-poly shapes, one colour per part, 2000 triangles. A photo-real cockpit is not possible; a charming chunky PS1 cockpit is. If your reference is detailed, point at the SHAPES and COLOURS you want, not the detail. Agent 8 should tell you what will be simplified.

## 7. Small habits
- One cockpit at a time. Get the Hauler right, then the others follow the same bones.
- Say "stop, wrong direction" early. Don't wait for the full batch.
- Keep a short list in the chat: "Already decided: window shape, dog on right, teal and amber light." Agent 8 must not change decided things.
- If the same note comes up twice, tell the Lead. Then I rewrite the brief instead of the agent guessing again.

## Message template for Agent 8
> Cockpit: <ship>. Reference pictures attached (marked). Three words: <...>. NOT: <...>. Proportion: <...>. Before modelling, show me 3 rough options A/B/C. After I choose, build only that one.
