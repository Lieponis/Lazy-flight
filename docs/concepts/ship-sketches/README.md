# Ship idea sketches (inspiration only, not part of the game)

Rough 2D concept sketches of 9 possible future ships, drawn by Agent 8 in November 2026 for Andy, as inspiration.
Nothing here is in the game or decided. The game still has its three ships (Cargo Hauler, Passenger Liner, Scout),
and these drawings do not change them.

## What it means

- **Style:** Andy chose style A, flat game colours with dark outlines, the same palette as today's ships.
  The shapes take ideas from Elite Dangerous (angular hulls), No Man's Sky (chunky, colourful) and Starfield (boxy
  modules), turned into our own designs.
- **Range classes (Andy):**
  - mid range is about the size of today's Passenger Liner;
  - long haul is bigger, with more windows, containers and engines;
  - heavy super long haul is cruise-ship or tanker size.
- **Passenger proportions:** bus, yacht and cruise ship.
- **Explorers:** angular, with wider bodies and extra attachments (dishes, tanks, pods, domes).
- **No weapons** on any ship.
- **Not drawn to final detail:** these are rough ideas. Turning any of them into a game model would be a separate
  decision and task. The game's "three ships" rule is untouched.
